# Metodología de entrenamiento de Aunara

Este directorio contiene reglas de producto para orientar rutinas. No contiene
diagnósticos ni protocolos de rehabilitación.

## Estado actual

- [Matriz metodológica v0.1](./workout-rules-matrix-v0.1.md): entregada al
  entrenador; feedback pendiente.
- [Registro de revisión](./2026-08-26-review-status.md): identifica la copia
  entregada y recibirá las observaciones.
- [Anexo de condiciones, adaptación y progreso](./condition-adaptation-progression-addendum.md):
  insumo posterior para la próxima revisión.

La versión 0.1 está en revisión y no está implementada. El anexo tampoco cambia
el producto actual. Toda versión aprobada debe identificar quién revisó
entrenamiento, cribado y lenguaje de seguridad, además de la fecha y el alcance
poblacional.

## Control de cambios

1. Crear una nueva versión; no sobrescribir una aprobada.
2. Relacionar cada cambio con evidencia o una decisión profesional documentada.
3. Ejecutar casos de prueba metodológicos y regresión funcional.
4. Mostrar la versión aplicada en la explicación de cada rutina sugerida.
